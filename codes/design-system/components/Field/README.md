# Field

Etiketli tek bir giriş veya seçim kutusu. `options` verilirse `select`, verilmezse `input` çizer; özel bir kontrol `children` olarak da verilebilir. Etiket büyük harf `label` stilindedir; ipucu ve hata metni altta durur.

- IP, port, COM, baud gibi teknik değerlerde `mono` kullanın.
- Hata metni ne yapılacağını söyler: "Port 1–65535 arasında olmalı."
