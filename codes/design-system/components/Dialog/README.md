# Dialog

Onay, bilgi, başarı ve hata mesajları; kaynaktaki `CustomMessageBox` (Enter / Cancel) ve ok, info, error, question ikonlarının karşılığı. `kind`: `question` (iki düğme), `info`, `ok`, `error` (tek düğme).

- Başlık konuyu, gövde sonucu ve sonraki adımı söyler.
- Yıkıcı onayda `destructive` verin; onay düğmesi işlemi adlandırır ("IP adresini değiştir"), "Evet" değil.
- Kullanan sağlar: arka plan örtüsü, odak tuzağı ve `Esc` ile kapatma.
