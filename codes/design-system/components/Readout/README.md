# Readout

Cihazdan gelen tek bir sayısal değeri etiket ve birimle gösterir: açılar, sıcaklık, odak uzaklığı, hedef merkezi. Değer `mono` ailesinde ve tabular rakamlarla yazılır, böylece güncellendikçe kaymaz.

- `tone="thermal"` IR kaynağına ait değerler (sıcaklık, IR odak) için; `accent` seçili/aktif değer için.
- `size="sm"` yoğun tablolarda.
- Birim ayrı verilir (`unit="°"`, `unit="°C"`, `unit="mm"`, `unit="px"`).
